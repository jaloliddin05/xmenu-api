# Справочник областей для зоны доставки

`build.ts` собирает `src/modules/delivery/regions/uz-regions.json`: 14 областей Узбекистана (ISO 3166-2:UZ), из
которых владелец собирает общую зону доставки заведения (`docs/API.md`, «Общая зона доставки заведения»). В сборку
скрипт не входит; результат коммитится.

```sh
npx ts-node --transpile-only scripts/delivery-regions/build.ts            # берёт скачанное из .cache/
npx ts-node --transpile-only scripts/delivery-regions/build.ts --refresh  # скачивает заново
```

## Источник и лицензия

- OpenStreetMap, отношения границ: `admin_level=4` (области), `UZ-QR` (Каракалпакстан) `admin_level=3`, `UZ-TK`
  (город Ташкент). Id отношений в таблице `REGIONS` в `build.ts`.
- Собранные мультиполигоны: `https://polygons.openstreetmap.fr/get_geojson.py?id=<relation>&params=0` (без
  упрощения). Версии и даты правок отношений: OSM API `relations.json`, пишутся в `source` справочника.
- Лицензия **ODbL 1.0**. Подпись «© OpenStreetMap contributors» (`attribution` в JSON и в `GET /delivery/regions`)
  показывается рядом с картой, где рисуются области. Справочник — производная база данных: распространяется на тех
  же условиях (ODbL), строка лицензии в JSON.
- geoBoundaries (gbOpen UZB ADM1) сравнивался и не взят: он сам сделан из OSM 2017 года, та же ODbL, сильно прорежен.

## Обработка

1. В OSM Ташкентская область покрывает город: `UZ-TO := UZ-TO − UZ-TK` (`polygon-clipping`), город становится дырами.
2. Кольца переводятся в `[lat, lng]` и размыкаются; куски меньше 1 га после вычитания отбрасываются (пишется
   предупреждение).
3. Упрощение Дугласа–Пекера в локальной проекции (метры): город Ташкент 30 м, остальные области 150 м. Ни одна точка
   исходной границы не дальше допуска от упрощённой.
4. Проверка той же функцией, что в API (`src/modules/delivery/domain/geometry.ts`): кольцо не пересекает себя и
   другие кольца области (после округления). Кольцо с нарушением упрощается заново с половинным допуском.
5. Округление до 6 знаков, `bbox` по кольцам.

Версия справочника `osm-ГГГГ-ММ-ДД` (дата сборки) копируется в каждую часть зоны вместе с геометрией: пересборка
сохранённые зоны не меняет. Проверки результата: `src/modules/delivery/regions/uz-regions.spec.ts`.
