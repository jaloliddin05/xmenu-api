# Контракт API филиалов

Фронт загружает филиалы через `src/features/branches/lib/branchesApi.js`.
Пока `NEXT_PUBLIC_BRANCHES_MOCK` не `false`, отдаётся демо-список из
`src/config/tenant.js` в том же формате, что описан ниже. Переключение на
реальный бэкенд — одна переменная окружения, компоненты менять не нужно.

Где используются филиалы: страница «Филиалы» (карта + список), выбор филиала
самовывоза в корзине, филиал по умолчанию в заказе, снимок филиала в заказе.

## Эндпоинт, который нужен клиенту

### `GET /branches`

* **Публичный**: без авторизации — гости смотрят филиалы тоже. Токен, если он
  есть, игнорируется. Тенант — по заголовку `X-Tenant-Id`.
* Только активные филиалы (скрытые/закрытые навсегда не отдавать).
* Порядок — как задан в админке (`sortOrder`); первый филиал клиент выбирает
  по умолчанию.
* Ответ `200`, массив (пустой массив — допустим):

```json
[
  {
    "id": "main",
    "title": "Mant 24/7",
    "address": "г. Ташкент, Чиланзарский р-н, ул. Бунёдкор, 12",
    "latitude": 41.2856,
    "longitude": 69.2034,
    "hours": "Круглосуточно",
    "phone": "+998711234567",
    "isOpen": true,
    "opensAt": null
  }
]
```

| Поле | Тип | Примечание |
|---|---|---|
| `id` | string | стабильный; именно его клиент шлёт как `branchId` в `POST /orders` |
| `title` | string | название |
| `address` | string | адрес одной строкой |
| `latitude`, `longitude` | number | WGS84; без координат филиал клиент отбросит (не нарисовать на карте) |
| `hours` | string | **готовая строка для показа** («Ежедневно 09:00–23:00»); собирается на сервере из расписания, локализация — по `Accept-Language` |
| `phone` | string \| null | для будущей кнопки «позвонить» |
| `isOpen` | boolean \| null | открыт ли **прямо сейчас** по времени тенанта (Asia/Tashkent); `null` — не знаем, тогда клиент ничего не блокирует |
| `opensAt` | string \| null | `"09:00"` — когда откроется, если сейчас закрыт |

Кэш: ответ меняется редко, но `isOpen` зависит от времени — рекомендуется
`Cache-Control: public, max-age=60` и `ETag`. Клиент хранит список 5 минут и
обновляет в фоне; при ошибке показывает старый список, а если его нет —
«Не удалось загрузить филиалы» с кнопкой «Повторить».

### Связь с заказами

* `POST /orders` принимает `branchId` из этого списка. Закрытый филиал →
  `409 branch_closed` с `details.opensAt` (код уже обрабатывается клиентом;
  он ещё и перезагрузит список, чтобы обновить `isOpen`).
* `isOpen` здесь и проверка в `POST /orders` должны считаться **одной и той
  же функцией**, иначе клиент покажет «открыто», а заказ отклонится.
* Неизвестный/выключенный `branchId` → `422 validation_error`.
* В объекте заказа приходит снимок `branch: { id, title, address }`.

## Что нужно бэкенду для хранения (рекомендация)

```
branches
  id, tenant_id, slug/id, title, address, latitude, longitude, phone,
  is_active, sort_order, timezone, accepts_pickup, accepts_delivery

branch_working_hours            -- расписание по дням недели
  branch_id, weekday (0-6), opens_at, closes_at, is_24h, is_closed

branch_hours_exceptions         -- праздники, ремонт
  branch_id, date, opens_at, closes_at, is_closed
```

`hours` (строка) и `isOpen/opensAt` вычисляются из этих таблиц. Учесть
ночные смены (закрытие после полуночи) и круглосуточные филиалы.

## Эндпоинты панели ресторана (токен сотрудника) — реализованы

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/branch` | все филиалы, включая скрытые, с расписанием и исключениями |
| POST | `/branch` | создать |
| PATCH | `/branch/:id` | поля, `isActive`, `sortOrder`, `telegramChatId`, `acceptsPickup/Delivery` |
| PUT | `/branch/:id/working-hours` | расписание целиком (`weekday` 1=пн … 7=вс; `closesAt <= opensAt` — ночная смена) |
| POST | `/branch/:id/exceptions` | исключение на дату `YYYY-MM-DD` (upsert) |
| DELETE | `/branch/:id/exceptions/:exceptionId` | убрать исключение |
| DELETE | `/branch/:id` | удалить; если есть заказы — только скрыть (`isActive=false`) |

`telegramChatId` — группа, куда уходят заказы этого филиала (бот должен быть в ней).
`phone` — номер для SMS-эскалации (`+998XXXXXXXXX`).
