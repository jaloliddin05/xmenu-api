# Тексты SMS (шаблоны для модерации Eskiz)

Все SMS, которые отправляет бэкенд, через какой бы провайдер они ни шли (`SMS_PROVIDER`). Eskiz пропускает только
заранее одобренные шаблоны: этот список подаётся на модерацию как есть. Переменные в фигурных скобках; всё остальное
текст бэкенда без изменений. Отправитель один на платформу (`ESKIZ_FROM`).

Переменные:

| Переменная | Что подставляется                                                                                               | Ограничения                                                                                                                                                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `{code}`   | одноразовый код                                                                                                 | только цифры, длина `OTP_LENGTH` (6)                                                                                                                                                                                                               |
| `{brand}`  | название заведения, очищенное `smsBrand` (`src/modules/auth/services/sms-brand.ts`)                             | буквы латиницы и кириллицы (включая узбекские), цифры, пробел, дефис, апостроф; до 30 символов; если название похоже на адрес сайта (`://`, `www.`, `имя.домен`), содержит 7+ цифр подряд (телефон) или пусто после очистки, подставляется `Xmenu` |
| `{venue}`  | то же, что `{brand}`; если `smsBrand` отказал, вместе с кавычками и пробелом перед ними не подставляется ничего | как у `{brand}`                                                                                                                                                                                                                                    |
| `{number}` | номер заказа в заведении                                                                                        | только цифры                                                                                                                                                                                                                                       |
| `{change}` | одна из фиксированных фраз ниже                                                                                 | —                                                                                                                                                                                                                                                  |

Свободный текст владельца (кроме очищенного названия) в SMS не попадает. Код по SMS гостю уходит только от
опубликованного заведения с включённым каналом «доставка» (`docs/API.md`, «Вход клиента»). Все SMS считаются в
суточные потолки (`SMS_DAILY_LIMIT_PLATFORM`, `SMS_DAILY_LIMIT_TENANT`).

## 1. Код входа гостя (сайт доставки, Mini App)

`POST /auth/customer/otp/request`, язык запроса (`customer-otp.service.ts`, `SMS_TEXT.customer`).

| Язык | Текст                                                             |
| ---- | ----------------------------------------------------------------- |
| ru   | `Код для входа в {brand}: {code}. Никому не сообщайте.`           |
| uz   | `{brand} ga kirish uchun kod: {code}. Hech kimga bermang.`        |
| en   | `Your {brand} sign-in code: {code}. Do not share it with anyone.` |

## 2. Код владельца или оператора (регистрация, сброс пароля, приглашение)

`POST /auth/register`, `/auth/resend-code`, `/auth/password/forgot`, `/auth/invitation/code` (`SMS_TEXT.staff`). Название
платформы постоянное: `{brand}` = `Xmenu`. Сейчас уходит только русский текст; uz и en есть в коде и подаются на
модерацию заранее.

| Язык | Текст                                                           |
| ---- | --------------------------------------------------------------- |
| ru   | `Код подтверждения Xmenu: {code}. Никому не сообщайте.`         |
| uz   | `Xmenu tasdiqlash kodi: {code}. Hech kimga bermang.`            |
| en   | `Xmenu confirmation code: {code}. Do not share it with anyone.` |

## 3. Регистрация на номер, у которого уже есть аккаунт

`POST /auth/register` для зарегистрированного номера: вместо кода (`staff-auth.service.ts`, `ACCOUNT_EXISTS_TEXT`), ru.

`У вас уже есть аккаунт Xmenu: войдите или восстановите пароль.`

## 4. Уведомление владельцу о критичном действии

После смены платёжных ключей, бота, ключа iiko, отключения iiko, удаления заведения или аккаунта
(`step-up/owner-security-texts.ts`), ru, на телефон владельца.

| Действие           | Текст                                                                                                           |
| ------------------ | --------------------------------------------------------------------------------------------------------------- |
| смена настроек     | `В Xmenu изменены настройки ({change}) заведения «{venue}». Если это были не вы, смените пароль.`               |
| удаление заведения | `В Xmenu удалено заведение «{venue}». Если это были не вы, срочно смените пароль и напишите в поддержку Xmenu.` |
| удаление аккаунта  | `В Xmenu удалён аккаунт владельца заведения «{venue}». Если это были не вы, напишите в поддержку Xmenu.`        |

`{change}`: `платёжные ключи`, `платёжные ключи Click`, `платёжные ключи Payme`, `Telegram-бот подключён или заменён`,
`Telegram-бот отключён`, `ключ iiko`, `iiko отключена`.

## 5. Филиалу: заказ ждёт подтверждения

Эскалация через 120 с без ответа (`order/queue/escalation.processor.ts`), uz, на телефон филиала.

`Xmenu: buyurtma №{number} tasdiqlanishini kutmoqda! Telegram guruhini oching.`

## Изменение текстов

Новый или изменённый текст SMS сначала проходит модерацию Eskiz, потом попадает в код, и в тот же PR правится этот
файл. Тексты SMS и бота проверяет `npm run check:user-texts` (`BOT_TEXT_FILES`).
